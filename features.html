Features

NextSteps is still just a concept, so none of these features actually exist yet. This page is more about explaining what the finished tool could eventually do if it were built.

Notes to Tasks

Meeting notes or a transcript could be turned into a list of separate tasks instead of one long block of text.

Project Organization

Tasks could be grouped by project so that work from different meetings doesn't get mixed together.

Due Dates

If a deadline is mentioned in the meeting, it could be attached to the task automatically instead of getting lost in the notes.

Assigned People

Tasks could be connected to whoever was responsible for them based on what was said during the meeting.

Breaking Down Big Tasks

Larger tasks could be split into smaller steps so they are easier to actually start working on.

Daily Checklist

Important tasks from several different projects could be combined into one simple list for the day.

Connected to the Original Notes

Each task could still be linked back to the original meeting notes in case someone needs more context later.

Future Calendar Integration

Down the road, this could possibly connect to a calendar app so due dates show up automatically.
